## Project

- Next.js 16 (App Router, all app code in `src/app/`), React 19, TypeScript (strict, `noEmit`), Tailwind CSS 4, ESLint 9 flat config. npm is the package manager (`package-lock.json` is the only lockfile).
- Frontend for a studio-rental platform. Routes: `/`, `/about`, `/how-it-works`, `/login`, `/register`, `/dashboard`, `/studios-explore`, `/studios-explore/[id]`.
- This repo is client-only. Data comes from a separate backend at `NEXT_PUBLIC_API_URL` (`.env` sets it to `http://localhost:5000`; endpoints used: `GET/POST /studiodata`, `GET /studiodata/:id`). Start that backend separately when testing data pages.
- `login` and `register` are UI shells — auth is not wired to the backend yet (see the `TODO` in `src/app/register/page.tsx`). Don't assume a token/session flow exists.
- Path alias: `@/*` → `./src/*`.

## Commands

- `npm run dev` — dev server (Turbopack). Also regenerates the auto-generated block above; commit it.
- `npm run lint` — ESLint (flat config, no extra args).
- `npm run build` — the only typecheck. There is no `typecheck` or `test` script; `next build` runs `tsc`. Order when verifying: `lint` → `build`.

## UI components (shadcn + Base UI)

- `src/components/ui/` is shadcn-generated with style **base-nova**: primitives come from `@base-ui/react`, *not* Radix. Don't hand-write Radix imports.
- Add components with the shadcn CLI (`npx shadcn add <component>`), configured by `components.json`.
- `cn` is re-exported from the `cn` npm package via `src/lib/utils.ts`.

## Repo-specific quirks

- Tailwind 4 is wired through a Turbopack loader rule in `next.config.ts` (`*.css` → `@tailwindcss/turbopack`). There is no `postcss.config.*` — don't add one.
- `images.remotePatterns` allows all `https` hosts; `experimental.agentFeedback` is enabled in `next.config.ts`.
- Global typed helpers like `LayoutProps<"/">` (used in `src/app/layout.tsx`, no import) are generated by Next into `.next/types`. They appear/refresh after `next dev` or `next build`; new routes get their own typed `PageProps`/`LayoutProps`.
- API studio records (`ApiStudio` in `src/type.ts`) have `_id: string | { $oid: string }` — MongoDB ObjectId may arrive as extended-JSON `{ $oid }`; normalize before using as a key/URL segment.
